Restore the approved release with the same command after pinning
`BLUNTS_IMAGE=blunts:web-a2631e9`. Confirm health through the public HTTPS origin,
then confirm the expected client hash and signing state. Use the previous
read-only image if identity, quote, fee or recovery behavior differs from the
qualified release. Preserve unknown wallet attempts and never replay them as an
operational recovery step.

## Remaining limits

The site is shipped. A real funded-wallet buy/sell still requires an eligible
holder to personally approve the financial actions. The checked wallet has no
USDG; no bank cash-out or direct brokerage connection is implemented by design.

Robinhood's public RPC is rate-limited and its documentation recommends a
provider for production traffic. The VPS path passed real reads; no production
load/SLA claim is established. The Cloudflare read-only experiment hit upstream
429s and was detached from the domain. It is preserved on local branch
`codex/cloudflare-edge-candidate-20261028` (`86e80eb`), with Worker and preview
URLs disabled. See [Robinhood connection guidance](https://docs.robinhood.com/chain/connecting/).

The VPS has pre-existing disk pressure (about 17 GiB free / 96% used); no unrelated
files were deleted. Kubernetes scheduling remains guarded. The app uses the
already-built image with bounded memory and logs, rather than bypassing the
scheduling taint. Infrastructure capacity and dedicated RPC admission are the
next operational tasks before substantial traffic, not hidden passed checks.
